# Project page: LEAF: Anchoring Visual Knowledge in Videos as People Do

Static project page served with GitHub Pages (Settings → Pages → `main` / root).

- `index.html`, `static/`: page, styles and scripts, based on the
  [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template)
  (CC BY-SA 4.0).
- `data/showcase.json`, `assets/`: generated by `scripts/export_showcase.py`, then
  `scripts/site_paper_sync.py` (numbers from the paper's tables, lanes for all fifteen backbones) and
  `scripts/build_site.py --keep-wall` (data chunks) in the main repository.

Local preview:

```bash
python -m http.server 8765
```
