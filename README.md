# Project page: Curating Educational Image–Text Pairs with Browser Agents

Static project page served with GitHub Pages (Settings → Pages → `main` / root).

- `index.html`, `static/`: page, styles and scripts, based on the
  [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template)
  (CC BY-SA 4.0).
- `data/showcase.json`, `assets/`: generated by `scripts/export_showcase.py` in the main
  `video_gui_agent` repository; re-run it there to refresh results and examples.

Local preview:

```bash
python -m http.server 8765
```
